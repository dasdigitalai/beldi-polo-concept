# Beldi Equestrian & Polo Club: concept redesign

A concept redesign of the Beldi Equestrian & Polo Club website (beldieq.com), by DAS Digital.
It is **not the official site**: the page carries a repeating SAMPLE watermark and is marked `noindex`.
Facility facts and addresses come from beldieq.com; the design and descriptive copy are ours.

Next.js 14 (App Router), no photography: the hero is drawn in SVG.

```
npm install
npm run dev     # http://localhost:3000
npm run build
```
